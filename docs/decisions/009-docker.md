# 009 — Docker and hosting

Date: 2026-11-16 · Status: accepted · Source: planning session, full plan in [../plan.md](../plan.md)

**Decision:** Docker from day one. Run on the user's Windows PC (Docker Desktop). Hosting is revisited in phase B.

**Why:** Containers keep the host choice open (home PC, small server, free-tier cloud).

**Rejected:** Running directly on Windows: harder to move later.
