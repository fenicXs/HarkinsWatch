# 008 — Ownership

Date: 2026-11-16 · Status: accepted · Source: planning session, full plan in [../plan.md](../plan.md)

**Decision:** The repository was transferred to the user's account (fenicXs) on 2026-11-16. The original author stopped using the project, so the user decides everything.

**Why:** Removes the need for owner-facing migration notes and permission workarounds.

**Rejected:** Staying a collaborator on someone else's repository: blocks renaming and managing settings and secrets.
