# 018 — Milestone order

Date: 2026-11-16 · Status: accepted · Source: planning session, full plan in [../plan.md](../plan.md)

**Decision:** M0 scaffold, M1 data layer, M2 bot shell, M3 Harkins watching, M4 Harkins booking and vision (legacy deleted), M5 BookMyShow, M6 plain-language requests, M7 District and PVR INOX.

**Why:** Reaches parity with the old bot first, so a working bot exists on the new stack before any new feature.

**Rejected:** BookMyShow straight after M2: gets the new feature sooner but leaves two bots running side by side for longer.
